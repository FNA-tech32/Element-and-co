🚀 Rawframe Studio

Rawframe Studio is a modern digital agency website built to showcase high-impact branding, web design, and creative production services.

🌐 Live Website: https://rawframe-studio.vercel.app

---

✨ About The Project

Rawframe Studio represents a bold, minimal, and high-performance digital agency focused on building brands that stand out.

The website is designed with:

- Aggressive minimalism
- Clean typography
- Modern UI/UX principles
- Smooth visual hierarchy

---

🧩 Features

- ⚡ Fast and lightweight design
- 🎯 Clean and modern UI
- 📱 Responsive layout (works on all devices)
- 🧠 Strong typography-focused branding
- 🖼️ Portfolio showcase section
- 🎨 Minimal yet impactful color scheme

---

🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Deployed on Vercel

---

🚀 Getting Started

To run this project locally:

git clone https://github.com/himanshu-nain-163/rawframe-studio.git
cd rawframe-studio
open index.html
