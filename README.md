# ⚡ Element&co

> **Monolithic High-End Digital, Branding & Creative Production Agency**

Element&co is a modern, high-impact digital agency website crafted to showcase elite brand identity, web architecture, and creative production. Built with aggressive minimalism, bold typography, and an acid-lime accent palette, Element&co delivers an uncompromising digital presence designed to make brands impossible to ignore.

---

## 🌐 Brand Overview & Philosophy

> *"We build brands that **don't** blend in."*

Element&co represents the forefront of modern digital agency aesthetics:
- **Aggressive Minimalism**: Stripping away noise to amplify core brand power.
- **Editorial Typography**: Pairing heavy display fonts (**Syne**, **Epilogue**) with technical monospace accents (**Berkeley Mono**) and readable body copy (**Inter**).
- **Tactical Creative Strategy**: Translating complex market positioning into high-converting digital ecosystems.
- **High-Contrast Acid Palette**: Distinctive `#b8ff3c` neon lime paired with deep carbon blacks and crisp neutrals.

## 🧩 Website Features

- ⚡ **Lightweight & High-Performance**: Pure semantic HTML5 + modern utility CSS.
- 📱 **Fully Responsive**: Fluid layout scaling effortlessly across mobile, tablet, and ultra-wide screens.
- 🎨 **Custom Theme Engine**: Tailored Tailwind CSS palette including custom surfaces, containers, and primary container tokens.
- 📬 **Interactive Project Inquiry Section**: Integrated client intake form with service selectors and submission feedback.
- 🔄 **Direct & Alternative Contact Channels**: Clear primary agency contacts combined with alternative expedited communication lines.
- 👁️ **Editorial Grain & Micro-interactions**: Subtle noise overlay and smooth hover states for an authentic physical/digital editorial texture.

---

## 💻 Tech Stack

- **Markup**: HTML5 (Semantic Structure)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (CDN with container-queries and forms plugins)
- **Typography**: 
  - [Syne](https://fonts.google.com/specimen/Syne) (Display Headlines)
  - [Epilogue](https://fonts.google.com/specimen/Epilogue) (Subheaders)
  - [Inter](https://fonts.google.com/specimen/Inter) (Body Text)
  - Berkeley Mono (Monospace Tags & Labels)
- **Icons**: [Google Material Symbols Outlined](https://fonts.google.com/icons)
- **Interactions**: Vanilla JavaScript for smooth form handling and navigation scrolling

## 🚀 Getting Started

### Prerequisites
All you need is a modern web browser (Google Chrome, Firefox, Safari, Edge).

### Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/element-and-co/element-and-co.git
   cd element-and-co
   ```

2. Open `index.html`:
   - **Direct browser**: Double-click `index.html` or drag it into any browser window.
   - **Local server (VS Code)**: Right-click `index.html` and select **Open with Live Server**.
   - **Python HTTP Server**:
     ```bash
     python -m http.server 8000
     ```
     Then open `http://localhost:8000` in your browser.
