# Element&Co

> High-end editorial digital agency website — branding, web design, and creative production.

Element&Co is a single-page marketing site built with aggressive minimalism, bold typography, and an acid-lime accent palette. It presents the agency’s capabilities, selected work, and direct contact channels.

---

## Brand & philosophy

> *"We build brands that don't blend in."*

- **Aggressive minimalism** — strip noise to amplify brand power
- **Editorial typography** — Syne / Epilogue headlines, Inter body, monospace labels
- **Tactical creative strategy** — market positioning as high-converting digital ecosystems
- **High-contrast palette** — `#b8ff3c` lime with carbon blacks and crisp neutrals

## Getting started

### Prerequisites

A modern browser (Chrome, Firefox, Safari, or Edge).

### Run locally

1. Open the project folder.
2. Open `index.html`:
   - Double-click the file, or
   - Use **Open with Live Server** in VS Code, or
   - Serve with Python:

     ```bash
     python -m http.server 8000
     ```

     Then visit `http://localhost:8000`.
